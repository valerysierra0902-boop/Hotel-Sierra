# Hotel Sierra — Sabores de Colombia

Sitio web estático responsive para una propuesta hotelera en Cartagena de Indias.

## Concepto y capacidad

- 12 habitaciones King Café × 2 huéspedes = 24 plazas. Tarifa orientativa desde COP $390.000/noche.
- 14 habitaciones Doble Queen Cacao × 4 huéspedes = 56 plazas. Tarifa orientativa desde COP $490.000/noche.
- 5 suites Caribe × 4 huéspedes = 20 plazas. Tarifa orientativa desde COP $790.000/noche.
- Total: 31 habitaciones y capacidad teórica de 100 huéspedes.

Tarifas propuestas, no cotizaciones confirmadas. Las fotografías son ilustrativas de terceros (Unsplash), no del hotel.

## Publicación en GitHub Pages

1. GitHub → repositorio → **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/(root)**. Guarda.
4. La dirección esperada es https://valerysierra0902-boop.github.io/Hotel-Sierra/ una vez que GitHub Pages indique publicación exitosa.

## Configuración antes de operar

En `index.html`, localiza `const HOTEL_WHATSAPP = '';` y escribe el número oficial con prefijo internacional, sin + ni espacios, por ejemplo `573001234567`. Sin número configurado, los botones abren WhatsApp con el mensaje prellenado, pero sin un destinatario específico.

El conserje 24/7 es un asistente local **basado en respuestas predefinidas**, no un modelo generativo; para IA real se necesita API y backend seguro, con credenciales fuera del código público. No ofrece disponibilidad real ni toma reservas.

Confirmar dirección, servicios, fotos autorizadas, impuestos, políticas y precios antes de presentar el sitio como negocio en funcionamiento.
